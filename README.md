# Piano Note Trainer

Juego para aprender a leer notas (clave de Sol y Fa) y encontrarlas en el piano.

https://echantermontreal.github.io/piano-note-trainer/

- **Leer**: ves la nota en el pentagrama y tocas la tecla.
- **Nombrar**: se marca una tecla y eliges su nombre.
- **Oído**: escuchas una nota y la buscas.
- **Progreso**: precisión y notas que necesitan práctica.

Instalar: iPhone (Safari) → Compartir → "Agregar a inicio". Android (Chrome) → menú ⋮ → "Instalar app".
